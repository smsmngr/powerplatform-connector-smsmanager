# SmsManager

SmsManager lets you send SMS and multi-channel messages to one or more recipients worldwide.

## Publisher: SmsManager

## Prerequisites
An SmsManager account. Sign up at https://www.smsmanager.com.

## Supported Operations
### Send message
Sends a message to 1–10 recipients. Optionally configure a delivery-receipt callback.

## Obtaining Credentials
1. Sign in to your SmsManager account.
2. Go to Account settings → API (https://app.smsmanager.com/app/developers/apikeys).
3. Create an API key and paste it into the API Key field when creating the connection.

## Getting Started
Create a connection with your API key, add the "Send message" action, fill in the message text and recipient phone numbers in E.164 format (e.g. +420777123456).

## Known Issues and Limitations
- Maximum 10 recipients per request.
- Maximum message length is 1000 characters.
